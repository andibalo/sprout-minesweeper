# About

Minesweeper console game made using node.js and typescript. Backend Engineer test for Sprout Digital Labs.
## Installation

Ensure you have the following installed
- node >= 21.7.3

Install dependencies by running:
```
npm install
```

Run development server by using the command below:
```
npm start
```
## How to play
1. (Optional) Input the grid length. Default is 3 and will create a 3x3 grid.
2. (Optional) Input the total mines on the grid. Default value is the grid length. Ensure total mines is less than the total number of grids.
3.  Input the grid coordinate row,column. Row and column are between 0 until n-1

## Run Tests

Run tests by using the command below:
```
npm test
```
